# 修订前后对照

## 身份知识泄漏

- 修订前：“罗主任早就知道她是周芩的女儿，却假装陌生。”
- 检查结果：`KNOWLEDGE_BOUNDARY_VIOLATION`，阻断；违反“罗主任在锁止完成及主动揭晓前不知道身份”。
- 修订后：删除该句，罗主任在看到旧检修册与工牌后才得知。
- 影响范围：仅修订该局部认知句；关键事件抽取列表前后保持一致。

## 未经批准的外援

- 修订前：“她母亲出钱找来专家，当场解决了问题。”
- 检查结果：`UNAPPROVED_EXTERNAL_RESCUE`，阻断。
- 修订后：保留江禾依据相位差与失败试验亲自调整阻尼索。

## 无关悬念尾巴

- 修订前：完整收束后追加“她收到一条神秘短信”。
- 检查结果：`UNRELATED_CLIFFHANGER`，阻断。
- 修订后：故事停在姐弟明确约定下一次共同做饭，保持完整收束。
