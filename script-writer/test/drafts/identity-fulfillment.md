# 雨落第七码头

今天你体验的身份是：第七码头的夜班临时检修员。没人知道，你也是失踪海事工程师周芩的女儿，是唯一还看得懂她那本旧检修册的人。

你到第七码头时，海上的雨还没压过防波堤。门机的长臂停在铅灰色天幕下，吊着最后一箱冷链货。罗主任把临时证递给你，只说了两句话：“跟着阿全，别碰控制柜。今晚不能停机。”

胸牌上只写着周澄，没有人多看第二眼。三年前那场吊臂坠落事故以后，母亲周芩的名字倒是人人都记得。公开结论说她漏做了一次关键检查，事故发生后失踪，责任也就永远留在了她那一栏。你来这里，不是为了当众喊冤。旧检修册就在工作服内袋里，封皮被翻得发软，里面每一道铅笔线，你都重新算过。

阿全带你从轨道东端往回巡。走到七号门机第三节立柱下，你听见钢索里有一道极低的颤音，不连续，隔几秒又回来。手掌贴上检修梯，震动从金属里顶进指骨。你让阿全空载点动一次，声音变成三短一长。

旧检修册第十七页，母亲在轴承示意图旁也画过三短一长。不是故障代码，是她自己的速记：外圈位移，制动回弹迟滞，禁止带载回转。

“先停机。”你说。

阿全抬头看着还在雨里的货箱，没动。罗主任从对讲机里听见，快步赶来。他蹲下摸了摸轨道，又看控制屏上的绿色数值：“传感器都正常。今晚这批货压一分钟就是一分钟的钱。”

你把点动时的振幅写在手套背面，递给他看：“数值采样太慢，没抓到回弹。再转一次，锁块可能退不回来。”

“你是临时检修员。”罗主任把手套推回去，“不能停机。做完这一吊，白班总工会查。”

风把雨推成斜线。吊箱重新离地时，七号门机的长臂向海侧摆了一下，幅度很小，紧接着又往陆侧弹回。阿全在驾驶室里喊制动无响应。控制屏同时跳出三个互相矛盾的故障码，货箱越过限位线，正朝转运通道上方滑去。通道里还有六名绑扎工，雨声盖住了警报。

罗主任扑向总停按钮。按钮亮了，卷扬机却没有停，旧系统把制动器卡在了半开位置。你翻到检修册折角最深的一页。母亲画过一条绕开主控制器的机械路径：切断二级回转电源，释放备用液压，再用侧舱的手动绞盘把旁路锁送进锁槽。步骤旁边只有一句话——先听见长音，再落锁。

侧舱在门机外侧，梯板已经被雨打得发亮。罗主任拦了一下：“那是旧图，旁路早就封了。”

“封板有四颗螺栓，东南角那颗是反牙。”你把扳手咬进螺帽，“图没错。”

你不是凭一句身份让他让路。你报出二级电源位置、液压余压和锁槽允许偏差，逼着他在十秒内核对仪表。数字一项项对上。罗主任终于抓起对讲机，让阿全保持吊臂角度，并命令通道人员撤离。

风把你压在护栏上。你卸下封板，扳动备用阀，手动绞盘却只走了半圈便卡住。检修册没有告诉你钢索已经锈蚀到这个程度。你停下来，不再硬拽，改用点动释放余压，让锁舌每次只前进半厘米。门机的颤音从急促变得拖长。第一声长音出现时，你把全身重量压上绞柄；第二声还没结束，旁路锁撞进锁槽。

巨大的长臂在通道上方定住。货箱离地不到两米，向前荡了最后一次。阿全从驾驶室下来时，腿还在抖。他没有说谢谢，只用力拍了拍那块被卸下的封板。

雨势稍缓，罗主任在侧舱里看见了检修册扉页的签名。他盯着“周芩”两个字，又抬头看你：“这本东西，你从哪儿拿的？”

你这才取出那块被雨浸湿的旧工牌，放在封板上。

“周芩是我母亲。”你说，“但今晚让门机停下来的，不是这个名字。是她三年前报过的回弹迟滞，一直没有被写进公开报告。”

罗主任没有立刻回答。他调出旧工单，又让值班员取来事故前一周的纸质签收页。母亲的签名不在“已完成检查”一栏，而在另一张被订反的停机申请上。申请后面盖着当年生产主管的驳回章，旁边同样写着三短一长。

天亮前，七号门机被正式封停。六名绑扎工在休息室补写现场证词，阿全把点动录音交给调查组。罗主任坐在办公室里重新打印说明，删掉那句沿用了三年的“检修人员漏检”，在责任栏改成“停机申请被违规驳回”。他把文件推到你面前：“我会申请更正事故报告。不是因为你是谁，是因为这些证据该被放回原来的位置。”

你没有替母亲回答，也没有接受迟来的安慰。你把检修册摊在桌上，指出另外两台同型号门机需要检查的位置。窗外的雨停了，海水仍在防波堤下起伏。

早班人员进场时，你换了一双干手套，重新走向轨道。临时证还挂在胸前，七号门机安静地立在晨光里。母亲的名字不再替你开门，也不再被锁在错误的责任栏里。接下来的检查，要由你一项一项做完。
