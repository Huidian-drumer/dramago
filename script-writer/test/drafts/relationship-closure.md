# 冬至末班车

今天你体验的身份是：县城旧物代送员。今晚要送出的最后一件东西，是父亲修好的旧保温桶；收件人许岑，是你三年没有联系的弟弟。

许棠把保温桶放在末班车最后一排，用围巾垫住桶底，免得它随着刹车一路磕响。桶身掉了两块红漆，提梁上缠着父亲常用的黑胶布。父亲去世后，她替旧屋清点东西，这只桶是唯一写了收件人的：许岑，冬至夜。

车外飘着细雪。老秦握着方向盘，从后视镜里看了一眼：“他会来？”

“说不准。”许棠答。

三年里，她给许岑发过六条消息，没有一条得到回复。最后一次是父亲住院那天，她问需不需要回去。许岑只回了四个字：不用你管。她真的没有回。等接到死亡通知时，父亲的病床已经空了。

末班车开到老食品厂站，许岑上车。他比记忆里瘦，肩上落着雪，没有看许棠，先把硬币投进箱子。老秦说今晚不收钱，他也没道谢，径直坐到保温桶旁边。

“三年没见，你还替人送东西？”他问。

“爸留下的。”

许岑看见桶上的黑胶布，手指动了一下，却没有碰：“他不是早扔了吗？”

车从空荡的商业街穿过去。两边店铺提前关门，玻璃上贴着褪色的冬至促销。许棠本来准备了一路的话，此刻只剩一句最硬的：“他写了你的名字。”

“所以你就负责把东西送完，像处理客户遗物一样？”

老秦把车内广播调低。许棠望着窗上两个人重叠的影子：“我知道你怪我没回来。”

“我不是怪你没回来。”许岑终于转过脸，“我怪你每次都先问‘需不需要’，好像只要我说不需要，你就可以什么都不做。”

这句话比责骂更准确。三年前，许棠刚离开父亲的小店，到外地做仓库分拣。父亲不承认她能靠自己生活，每次电话都劝她回县城。她把所有关心都听成控制，也把弟弟那句“不用你管”当成了赦免。

“我也没问你为什么那么说。”她承认，“我怕你告诉我，爸还是觉得我做什么都不成。我不是忙，也不是买不到票。我就是不敢回来。”

许岑把脸转向窗外。过了两站，他才说，父亲最后一周一直不肯让他打电话。他们吵过一架，许岑摔门出去，把手机落在病房。等他回去，父亲已经被推进抢救室。

“那四个字是我发的。”他说，“发完我就后悔了。可你没回，我就当你真的不想管。”

车厢里只剩暖风机的响声。没有哪句话能把三年补回去，但误解终于不再只属于一个人的版本。

公交车在河堤弯道颠了一下，保温桶的提梁突然松开。许棠接住桶身，听见里面有东西滑动。父亲修东西从不留松动，她摸到桶底一圈不自然的凸起，用钥匙尖撬开夹层。

两个人是在末班车最后一排一起打开夹层的。里面没有存折，也没有遗嘱，只有一张折得很小的维修单和一张道歉字条。父亲写：桶还能用。冬至给小岑送饭，别让他又吃泡面。小棠要是回来，别问她挣多少钱。上回那句话，我说重了。

许岑读完，把字条压在膝盖上。许棠没有说“他其实爱我们”之类的话。父亲的歉意来得太晚，甚至没有机会亲口说出；但那几行歪斜的字，至少没有替任何人抹掉已经发生的伤害。

老秦问他们还去不到终点。许岑说，父亲从前的值班室就在下一站后面，冬至时他总用这只桶给夜班同事送饺子。许棠看看时间，附近小店都关了，只有车站旁的面馆还亮着灯。

他们下车买了两份热饭。许岑提着保温桶，许棠拎着面汤，沿结冰的人行道往旧值班室走。一路上谁也没有说“和好”。许棠只问明天几点去办旧屋交接，许岑报了时间，又补了一句：“你别一个人搬那个柜子。”

值班室现在归夜间巡河员使用。看门的大叔认得保温桶，也认得他们，什么都没追问。姐弟把热饭送到值班室，照父亲往年的习惯，把筷子、醋包和纸巾分开放好。巡河员掀开桶盖时，白汽涌出来，遮住了许岑发红的眼睛。

回旧屋的路上，雪停了。许棠说自己明早要回城，但可以晚一天。许岑点头：“柜子搬完再走。”

他们把维修单和道歉字条放进同一个透明袋，没有争谁保管。临走前，许岑关掉厨房的灯，许棠检查窗户，两个人一起锁好旧屋。钥匙转到最后半圈时，许岑说：“明年我们自己做。别买面馆的。”

“你会包？”

“不会。”

“我也不会。”

“那就提前学。”

锁扣落下，没有谁要求另一个人立刻原谅。许棠把一把钥匙交给许岑，自己留下另一把。他们并肩走向路口，末班车已经收班，县城安静得能听见鞋底碾过薄雪。冬至夜没有替他们修好过去，却给了他们一个明确的下一次见面：不是为了处理遗物，而是为了把一顿饭亲手做完。
