# DramaGo Future Productization Roadmap

本文件只记录未来产品化方向，不代表已实现、已排期或已通过验证。

| 路线 | 未来目的 | 当前状态 |
|---|---|---|
| Cloudflare Queue | 将长文本任务从浏览器请求生命周期中解耦 | 不实现 |
| Durable async Writer | 支持持久化执行、有限重试和幂等候选 | 不实现 |
| 独立 D1 | 让 API Worker、Queue Consumer 与数据处于同一可控账号 | 不实现 |
| 用户认证 | 隔离作品、任务和模型额度 | 不实现 |
| API 防盗刷 | 限制公开 API 滥用与模型费用风险 | 不实现 |
| 计费 | 支持额度、订阅或按量使用 | 不实现 |
| Narrative Memory | 为跨集创作维护长期事实与人物状态 | 不实现 |
| 图片生成 | 将文字内容扩展为视觉资产 | 不实现 |
| 视频生成 | 从文本或分镜进入视频生产 | 不实现 |
| TTS | 生成旁白或角色语音 | 不实现 |
| StoryWorld | 提供实时互动叙事与世界状态 | 不实现 |

## 启动条件

只有当产品从“求职作品集 / 可演示 Demo”重新进入生产化目标，并明确用户、使用频率、成本上限与发布渠道后，才重新评估上述路线。

当前保留现有 Sites 环境和数据，不执行迁移、删除或基础设施扩张。
