DramaGo / Product

为创作自由建立可靠边界

DramaGo 不替作者做内容判断，而是让生成、局部编辑、连续创作和版本采用变成可追踪的产品流程。

PRODUCT PRINCIPLE

模型写作，程序守边界。

模型负责

  • 生成完整正文、片段或续写
  • 理解作者要求与有限语义关系
  • 在独立执行的 Validator 阶段报告事实与约束风险

程序负责

  • scope、selection、merge 与 append
  • source version、candidate、content hash 与 CAS
  • output_kind、尺寸限制、证据门槛、错误保护与 adopt

OPERATIONS

四种操作的真实差异

CREATE

full

当前 UI 通过 Direct Writer 建立完整候选稿。

EXPAND

segment

只扩写可靠选区，由程序将片段合并回源文。

REWRITE

full / segment

整篇或局部重写，并保留来源版本与影响范围。

CONTINUE

continuation

只生成新增内容，由程序追加，前文不会被整篇重写。
