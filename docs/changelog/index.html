v0.5.0 — Validated Portfolio MVP

Released

Validated 指工程工作流验证、受控真实模型实验与小样本人工盲评，不表示市场验证、生产可靠性验证或 SLA。

Product

  • CREATE / EXPAND / REWRITE / CONTINUE 完整创作工作流。
  • Candidate / Version / Adopt、scope / merge、output contract、source version CAS 与 hash binding。
  • Version/hash-bound Story Facts validation snapshots 与模型辅助 Semantic Validator V2；程序执行阻断与采用控制。
  • 实验性 API / benchmark Content Intelligence；v0.5.0 UI 不提供开关。

Evidence

  • 公开 Wrapper Audit、项目内部 L2 Hardening、Golden Set、Writer latency 与 Validator calibration。
  • 保留 V4-Pro 正式实验中的取消、fetch failure、HTTP 500 与 abandoned 结果。
  • 公开 DeepSeek Flash 3-case 人工盲评及 selective—not universal—benefit 结论。

Project system

  • GitHub/Primer-inspired 静态产品站与完整文档信息架构。
  • Light / Dark / System 主题、移动导航、语义结构与 reduced-motion 支持。
  • README、Architecture、ADRs、Release Notes、Roadmap 与公开证据包。

v0.5.0 基于内部迭代工作树整理为公共 release snapshot，同时保留既有 GitHub 公共历史。它不是生产 SaaS 发布。
