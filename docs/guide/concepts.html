Environment & Errors

Creative Brief

一次创作操作的规范化输入，包含作者要求、目标范围、required outcomes、hard/soft preserve、negative constraints 与目标长度。它会影响执行，但不能绕过程序化范围和版本规则。

Candidate Version

模型生成结果不会直接覆盖当前作品，而是作为 candidate 保存。候选保留来源版本、正文 hash、校验状态与是否可自动采用等信息。

隔离原则：Provider 失败、Validator 阻断或 source version 冲突都不会破坏源稿。

Story Facts

Story Facts 是由 Validator LLM 提取、与来源版本和正文 hash 绑定的轻量语义校验事实快照，包括人物、关系、不可逆事实、重大事件和时间锚点。后续 Validator 可以读取；用户明确改写事实时允许更新。

IMPORTANT：Story Facts in v0.5.0 are validation snapshots, not a Narrative Memory system. They are extracted by the Validator, bound to a version and content hash, and reused by later validation stages. The Writer does not consume Story Facts directly.

Semantic Validator

Writer 之后独立执行的模型辅助语义校验阶段，检查事实、时间线、hard preserve、required outcomes、negative constraints 和候选内部一致性。模型报告判断，程序执行 finding allowlist、severity、confidence、evidence、source priority、hash 绑定、can_auto_apply 与 CAS adopt；Validator 不修改正文，也不是独立真值系统。

  • 直接事实或时间线矛盾可以 blocking。
  • “减少”“尽量”、风格和节奏问题默认 warning。
  • 阻断必须包含允许类别、置信阈值和非空 evidence。

Content Intelligence

这是 CREATE 的 experimental、API-level 可选结构增强：Planner LLM 生成短 ContentPlan 并返回人工策划机制库中的 ID；程序仅执行 known-ID allowlist、去重、最多 5 条、持久化与 traceability，Writer 是否兑现仍由 Prompt / model 决定。v0.5.0 UI 没有开关，普通 CREATE 默认走 Direct Writer。人工盲评只显示 selective—not universal—benefit。
