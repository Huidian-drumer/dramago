Environment & Errors

Requirements

  • Node.js 20+
  • pnpm
  • D1-compatible 数据库绑定
  • OpenAI-compatible 文本 Provider

Install and verify

git clone https://github.com/Huidian-drumer/dramago.git
cd dramago
pnpm install --frozen-lockfile
pnpm test
pnpm build
pnpm validate
pnpm audit:l2
pnpm db:validate

Configuration

复制 .env.example，仅在服务端环境中设置 Provider 配置。

VariableRequiredPurpose
OPENAI_API_KEYYesOpenAI-compatible Provider secret
OPENAI_MODELYesWriter model
OPENAI_ENDPOINTNoProvider chat completions endpoint
VALIDATOR_MODELNoModel used by the separate semantic-validation stage
MAX_AUTO_REPAIRSNoFormat repair limit, capped by code

不要提交 Secret：API Key 不应进入 Git、前端、数据库、日志或 Creative Trace。GitHub Pages 只承载静态官网。

Preview

pnpm preview

命令会启动本地 Worker 工作台预览。GitHub Pages 文档是独立静态站，可用任意静态服务器从 docs/ 目录预览。
