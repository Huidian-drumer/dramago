Overview

DramaGo v0.5.0 是验证型 AI 短剧创作工作台 MVP。它把模型生成包在可审计的操作、范围、版本与候选采用逻辑中，而不是直接把模型全文写回作品。

当前定位：作品集 Demo 与工程验证载体。Validated 指工程验证、受控真实模型实验和小样本人工盲评，不是市场验证或带生产 SLA 的 SaaS。
