CREATE

创建完整作品候选。v0.5.0 UI 直接进入 Writer，不提供 Content Intelligence 开关；后端 API / benchmark 可显式请求 experimental ContentPlan + Mechanism Retrieval 支线。

EXPAND

选区扩写要求 Provider 返回 segment。程序使用 selection range 合并，重复句不会通过全文搜索误改第一处。整篇冒充片段会返回 OUTPUT_KIND_MISMATCH。

REWRITE

作者本轮显式修改优先于旧 ContentPlan、Skeleton 或结局。局部重写只替换目标范围；整篇重写保存为新的 candidate，不直接覆盖 source。

CONTINUE

Provider 只生成新增内容并声明 continuation，程序负责 append。Writer 直接接收 source version 的正文作为生成上下文；Story Facts 快照只供后续独立执行的模型辅助 Semantic Validator 使用，当前不会直接注入 Writer。

共同规则：所有操作都要经过输出尺寸、格式、source current 状态和单独的语义校验阶段；Provider 失败不会使用固定正文冒充结果。
