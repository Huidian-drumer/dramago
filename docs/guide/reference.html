Environment & Errors

Server environment

NameMeaning
OPENAI_API_KEYProvider secret；仅服务端读取
OPENAI_MODELWriter model
OPENAI_ENDPOINTOpenAI-compatible chat completions endpoint
VALIDATOR_MODEL独立执行的模型辅助 Validator 阶段所用模型；可 fallback 到 Writer model
PROVIDER_TIMEOUT_MS单次 Provider 尝试窗口
MAX_AUTO_REPAIRS格式修复次数上限

Key error codes

CodeMeaning
PROVIDER_NOT_CONFIGURED服务端 Provider 缺少必要配置
PROVIDER_TIMEOUTProvider 在允许窗口内未完成
OUTPUT_KIND_MISMATCHfull / segment / continuation 与操作不符
OUTPUT_TOO_LARGE响应超过集中安全上限
SOURCE_VERSION_CONFLICT任务来源已不是当前作品版本
VALIDATION_STALE正文 hash 与绑定 checks 不一致
FORMAT_INVALID格式修复后仍无法满足契约

Known limitations

  • 同步长文本请求仍会受到 Provider 与宿主运行窗口影响。
  • Semantic Validator 依赖模型，不能识别所有事实或时间线问题，也不是独立真值系统。
  • Content Intelligence 只在少量人工盲评中表现出选择性增益，并且 v0.5.0 UI 未提供开关。
  • 没有账号、计费、durable async Writer、高并发或生产 SLA。
  • 当前只覆盖文字创作，不包含图片、视频与 TTS。

公开 Demo 可能要求授权访问；GitHub Pages 本身只承载静态项目官网，不承载服务端密钥。
