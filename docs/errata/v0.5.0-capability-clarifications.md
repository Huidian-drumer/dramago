# v0.5.0 Capability Clarifications

Status: post-release documentation clarification. No v0.5.0 product code, benchmark result, tag or GitHub Release was changed.

## Story Facts

Story Facts are version/hash-bound validation fact snapshots extracted by the Validator and reusable by later validation stages. The Writer does not consume them directly. They are not Narrative Memory, Writer Memory or a complete character-state engine.

## Content Intelligence

Content Intelligence V0.1 is an experimental, API-level optional CREATE enhancement used by benchmarks. The v0.5.0 UI does not expose a toggle and its CREATE action uses Direct Writer. A Planner LLM chooses mechanism IDs; program code performs allowlisting, deduplication, a maximum-five cap, persistence and traceability. Writer fulfillment remains model-mediated.

## Semantic Validator

Semantic Validator is a separate model-assisted validation stage with programmatic enforcement. It may use the same Provider or model as Writer. The model judges semantic relationships; the program enforces evidence, severity, confidence, source priority, hash binding and safe adoption. It is not an independent truth engine or formal proof.

## Legacy components

`script-writer/` and `/experience` are retained historical experiments, not the current authoring runtime. The v0.5.0 runtime is under `worker/ + web/ + db/`.
