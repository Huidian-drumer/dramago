WHY DRAMAGO

一次生成，不等于一个可靠的创作产品。

普通聊天式 AI 可以写出文本，却很难稳定管理局部编辑、连续事实与版本采用。

  • 局部修改可能重写无关内容。
  • 长篇连续创作会遗失已经成立的事实。
  • 生成历史与候选来源难以审计。

产品问题

如何在不限制作者创作自由的前提下，让模型输出经过可检查的程序边界，再进入作品版本？增加更多 Agent 并不会自动解决这个问题。

CORE OPERATIONS

四种操作，四套明确的程序行为。

区别不只是 Prompt 中的 operation 字符串。

full

EXPAND

segment

扩写可靠选区，程序保留范围外正文并完成精确替换。

scopeselection / full

REWRITE

full / segment

按作者意图改写整篇或局部，并管理来源版本与影响范围。

scopeselection / full
mergereplace

CONTINUE

continuation

模型只返回新增内容，程序追加；已存在的前文不会交给模型重写。

scopeafter source

CONTENT INTELLIGENCE EXPERIMENT

更多 Agent，并没有自动带来更好的内容。

ContentPlan + Mechanism Retrieval 的价值通过真实模型和人工盲评验证，而不是由模型自己打分。

01 / HYPOTHESIS

结构增强可能改善 CREATE

尤其是身份承诺容易在正文中丢失的场景。

02 / METHOD

相同 DeepSeek Flash

同一输入、同一目标长度，Direct 与 Enhanced 各生成一次。

03 / REVIEW

3-case human blind A/B

盲评稿不暴露 A/B 映射、Planner、耗时或校验元数据。

04 / DECISION

selective—not universal

Content Intelligence 保持可选，而非默认 CREATE Pipeline。

CaseHuman blind preferenceObserved product lesson
Hidden heirEnhanced更好地把身份 setup 转化为因果与 payoff。
17-year-old emperorDirect Writer额外规划让缺少经验的角色显得过于成熟。
Regret-vision abilityDirect WriterDirect Writer 已自然推演能力边界，Planner 增益不足。

PRODUCT DECISIONS

把取舍写进产品，而不藏在演示背后。

ADR-001 · ACCEPTED

程序约束优先于 Prompt 自律

范围、合并、版本与采用必须由程序执行。

ADR-002 · ACCEPTED

Validator 只做安全层

不把文风、爽感或“爆款”判断升级成硬阻断。

ADR-003 · ACCEPTED

Content Intelligence 保持可选

只在结构缺口真实存在时增加规划成本。

ADR-005 · DEFERRED

生产基础设施延后

Queue、durable Writer、账号和计费不是当前作品集 MVP 范围。
