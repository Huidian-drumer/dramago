Four distinct operations

四种操作，不是四句不同的 Prompt

每种操作都有独立输出契约与程序行为。选区、合并、追加和版本保护不依赖模型“自觉”。

Execution pipeline

去掉模型智能，产品仍然有逻辑。

DramaGo 把一次生成拆成可追踪的执行阶段。模型输出不能绕过范围、类型、版本与校验约束直接覆盖作品。

阅读完整 Wrapper Audit ↗
  1. 01
    Creative Brief

    作者要求、目标范围、required outcomes、hard / soft preserve。

  2. 02
    Operation Router

    CREATE、EXPAND、REWRITE、CONTINUE 进入不同程序路径。

  3. 03
    Output Contract

    强制 full、segment 或 continuation；类型不符立即失败。

  4. 04
    Merge & Append

    选区替换和续写追加由程序执行，不接受模型整篇偷换。

  5. 05
    Semantic Validator

    独立检查 Story Facts、承诺兑现、preserve 与明显时间线冲突。

  6. 06
    Candidate & CAS

    候选稿隔离保存；来源版本变化时禁止覆盖当前作品。

Evidence, not self-scoring

通过可复现的失败场景证明保护能力

测试不为了全绿而降低标准。无法证明的语义能力会被诚实标记为 pipeline-only 或 unavailable。
