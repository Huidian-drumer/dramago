故事由你决定。
修改有范围，采用有依据。

开戏 DramaGo V1.4 是 Windows 文本创作工作台。管理作品与草稿，阅读、比较和恢复版本，让 AI 的新稿先成为候选，再由你决定是否采用。

V1.4 Public PreviewMIT Source非生产级 SaaS
查看源码 ↗开发与数据安全

本次仅发布源码与版本说明，不提供 Windows ZIP。GitHub 的 Source code 压缩包不是安装程序。此官网不运行模型 API。

从想法到正式正文流程说明
  • 01写作与操作手工编辑，或明确选择生成、扩写、改写、续写
  • 02独立候选新稿不会直接覆盖当前正式正文
  • 03检查与比较内容约束、来源版本及正文 Hash 分别核对
  • 04手动采用满足门禁后，由作者确认；CAS 保护较新版本

V1.4 CAPABILITIES

阅读、创作与版本管理，在同一处衔接。

本地文本工作台

空白作品与命名、手工写作、SQLite 草稿、多作品切换、Markdown 导出。程序目录与用户数据分离。

四种创作操作

CREATE 建立完整候选；EXPAND / REWRITE 管理局部范围；CONTINUE 由程序追加并保留来源正文。Writer 和 Validator 可以独立配置。

可追溯的版本

版本比较、历史只读查看与安全恢复；候选和正式正文分离，采用仍需 Hash、来源绑定和 CAS 校验。

保守的 Story Memory

正式记忆绑定已采用版本，证据和状态不足时保守处理。它不是任意中文事实的真值系统。人物关系树已从 UI 移除，可靠记忆能力保留。

HONEST BOUNDARIES

公开预览，not a production SaaS。

  • 真实 Writer 文学质量与 Validator 语义准确率尚未完成系统性验收。
  • 检查通过只代表当前检查结果，不代表故事质量优秀；复杂事实与合理剧情变化仍需作者判断。
  • 本次构建与核心测试使用合成文本、受控 Provider；不等于所有模型都已验证兼容。
  • 没有视频生成、TTS、场景分镜或角色视频一致性能力。
  • 不得把本地创作服务直接开放公网；免费 SaaS 尚未部署。
